
# T A N J I L 🎀 — CYBER IDENTITY

A futuristic personal portfolio website.

## Features

- Cyberpunk-inspired responsive UI
- Personal information
- Social media connections
- Dynamic QR code generator
- Downloadable contact card
- Node.js and Express backend
- Health monitoring endpoint

## Requirements

- Node.js 20+
- npm
- Git

## Installation

```bash
npm install
```

## Run locally

```bash
npm start
```

Open:

http://localhost:3000

## Development

```bash
npm run dev
```

## Health Check

http://localhost:3000/health

## QR Generator

http://localhost:3000/api/qr?text=https%3A%2F%2Fexample.com

## Render Deployment

Build Command:

npm install

Start Command:

npm start

Environment:

NODE_ENV=production
